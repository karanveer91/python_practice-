# Python Practice Questions 🐍

A collection of Python practice questions designed to help beginners and intermediate learners improve their programming skills.

This repository contains multiple coding exercises that cover Python fundamentals and problem-solving techniques. The goal is to help learners build strong programming logic through consistent practice.

---

## 📚 Topics Covered

The practice questions in this repository cover the following topics:

* Basic Input and Output
* Variables and Data Types
* Arithmetic Operators
* Conditional Statements (if, elif, else)
* Loops (for loop, while loop)
* Functions
* Lists
* Tuples
* Dictionaries
* Strings
* Mathematical Problems
* Logical Problems

---

## 🎯 Purpose of This Repository

* Practice Python programming
* Improve logical thinking
* Strengthen coding fundamentals
* Prepare for coding interviews
* Help beginners learn Python step by step
